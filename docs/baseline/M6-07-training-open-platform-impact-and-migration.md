## 2. 业务定位与范围

本阶段帮助店长回答“哪些技师具备当前有效资格”，并允许经过授权的外部系统只读获取本店公开项目目录。培训不是泛化网课平台，开放平台也不是把内部 V3 接口直接暴露出去。

当前非目标：视频托管、在线考试题库、自动发证机构对接、会员/护理/支付/库存开放、外部写预约、Webhook、OAuth、跨租户客户端、真实生产密钥导入。

## 3. 影响模块

| 模块 | 影响 |
|---|---|
| training | 拥有课程、培训记录、状态策略和追加历史；校验员工门店任职 |
| integration | 拥有客户端、密钥摘要、轮换/撤销事件、请求审计、Nonce 与限流 |
| masterdata | 通过公开查询端口返回开放项目目录；集成模块不得直读项目私有表 |
| security | 新增培训与集成权限；开放接口使用独立客户端身份，不伪装为员工账号 |
| audit/outbox | 关键管理动作写审计/安全业务标识事件，禁止敏感正文 |
| admin-next | 新增“培训与开放平台”任务页，分区呈现培训运营与集成治理 |
| front-next | 技师工作台增加本人培训记录和受控开始/提交动作 |

不修改预约、护理、订单、支付、退款、套餐、库存、提成、售后或营销历史事实。

## 4. 状态与权限

课程状态：`DRAFT -> ACTIVE -> RETIRED`。草稿可按 `version` 修改；发布后不可覆盖，修改内容必须创建新版本。

培训记录状态：

```text
ASSIGNED -> IN_PROGRESS -> SUBMITTED -> PASSED
                         |             -> FAILED
ASSIGNED / IN_PROGRESS ----------------> CANCELLED
PASSED --------------------------------> EXPIRED（按有效期派生或受控任务更新）
```

- 技师只能查看本人记录，并对本人 `ASSIGNED/IN_PROGRESS` 执行开始或提交；
- `training:verify` 才能通过/不通过，验证人不得是受训技师绑定账号；
- 通过记录保存课程版本、得分、证书编号和有效期，不覆盖旧记录。

开放客户端状态：`ACTIVE -> REVOKED`，撤销不可逆；轮换增加密钥版本并立即废止旧摘要。权限拆分为 `integration:view/manage/rotate`；培训拆分为 `training:view/manage/verify/self`。

## 5. 数据库迁移

计划迁移：`V2026080103__m6_training_open_platform.sql`，expand-only 新增：

- `training_course`
- `training_record`
- `training_record_history`
- `integration_client`
- `integration_client_event`
- `integration_request_log`

关键约束：

- 课程编码与版本在租户/门店内唯一；课程状态、通过分数和有效期有 CHECK；
- 培训分配幂等键唯一；状态、时间、分数和证书字段受一致性 CHECK；
- 历史按记录与幂等键唯一，只追加不提供更新/删除接口；
- 客户端编码在租户/门店内唯一，密钥只保存 SHA-256 摘要和安全前缀；
- 客户端事件按客户端、动作幂等键唯一；
- 请求日志按客户端与 Nonce 唯一，支持客户端/时间和结果索引；
- 所有业务外键显式包含租户/门店边界或由应用服务在同一事务校验。

## 6. 开放接口安全契约

- 管理接口继续使用员工 V3 Bearer 会话；开放接口使用 `X-Integration-Client` 与 `Authorization: Bearer <一次性密钥>`；
- 每次开放请求要求 `X-Integration-Timestamp`、`X-Integration-Nonce`，时间偏差最多 5 分钟，Nonce 不可重复；
- 当前唯一可授予作用域为 `catalog:read`，唯一开放业务接口为本客户端绑定门店的公开项目目录；
- 每分钟请求上限由客户端配置并由数据库请求账本执行，超限返回 429；
- 响应仅含项目编号、名称、分类、时长和公开价格，不含会员、员工联系方式、护理、健康、支付或内部审计信息；
- 密钥只在创建和轮换成功响应中返回一次，列表、详情、日志和错误不得回显。

## 7. 兼容、发布与回滚

- `/api/v1`、`/api/v2` 和既有 `/api/v3` 行为不变；旧应用忽略新增表与权限；
- 先迁移再发布管理路由，最后启用开放过滤器和开放路由；未创建客户端时外部访问统一 401；
- 应用回退时关闭培训/集成菜单和路由，撤销全部新客户端或停止开放过滤器，新表保留只读；
- 不删除课程、培训历史、客户端事件或请求审计；需要纠错时追加新版本、培训记录或事件；
- 反向 DDL 仅在完成独立备份、确认无业务数据、满足审计留存并经单独审批后执行；默认生产策略不物理回滚。

## 8. 验收门禁

- 测试数据只使用合成员工、合成课程和随机测试密钥；
- 数据库中搜索不到签发的完整密钥；旧密钥轮换后和客户端撤销后均返回 401；
- 跨租户、跨门店、无作用域、过期时间戳、重复 Nonce、超限请求均被拒并留下无敏感信息审计；
- 培训非法转换、越权本人、同人验证、版本和重复请求均被拒；
- 管理端与技师端白色主题页面在桌面和窄屏无横向溢出，错误与空状态可理解；
- 测试、构建、迁移、隔离 API、浏览器和文档全部通过后才能标记 M6-07 完成。
