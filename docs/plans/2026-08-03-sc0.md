# SC0 实施计划：范围冻结与旧入口收口

日期：2026-08-03

执行边界：仅 SC0，不进入 SC1，不修改业务功能。

## 目标

将当前交付口径从 V2.1 的多端、多角色范围收口到 V3.0 的两端范围，并把该边界转化为可追溯、可自动校验的仓库契约。

## 实施步骤

1. 新增 `scripts/verify-sc0-scope.ps1`，先证明现状不满足 V3.0 范围契约。
2. 更新根目录 `PRODUCT.md`、`DESIGN.md`、`README.md`，新增 `CONTRIBUTING.md`，明确当前两端产品、统一后端、未来小程序复用及冻结范围。
3. 新增 `docs/architecture/v3-scope-module-matrix.md`，输出保留/复用/冻结/新增模块矩阵；更新客户端与部署架构文档，区分当前交付面和冻结兼容资产。
4. 在 V2.1 历史 PRD 顶部增加“已被 V3.0 取代”的文档控制声明，保留原文作为历史依据。
5. 从 `front-next/src/views/LoginView.vue` 删除指向 `8283` 的技师端导航链接；保留技师端代码、迁移、接口和兼容容器服务。
6. 执行范围契约、现有前后端测试、前端构建和差异检查；输出 `docs/verification/SC0/SC0-verification.md`。
7. 创建 SC0 提交和注释标签，报告结论并停止，等待人工回复“通过，进入 SC1”。

## 不在本阶段执行

- 不改变权限、路由守卫、业务接口、数据表或迁移。
- 不删除技师端、复杂多角色后台、采购、提成、培训等既有代码。
- 不实现 SC1 差距分析或任何后续业务功能。

## 验收条件

- V3.0 两端范围在核心文档中一致。
- DEMO 会员登录页不再展示技师端入口。
- 冻结代码与数据库资产仍存在。
- 自动范围契约通过，既有测试和前端构建通过。
