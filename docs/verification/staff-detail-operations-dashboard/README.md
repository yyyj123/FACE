## 交付内容

- 用户端首页技师卡片改为统一摘要卡片，点击进入 `/client/staff/:id` 独立详情页。
- 详情页展示照片、职级、个人介绍、完整擅长项目和预约入口；预约页识别 `staffId` 并在选定项目后预选技师。
- 运营管理平台首页移除技术栈和迁移检查，改为真实业务数据驱动的 ECharts 看板。
- 看板包含预约与实收趋势、预约状态、热门护理项目、会员新增和技师服务负荷，支持门店以及近 7/30/90 天筛选。
- 新增只读运营汇总接口和 `analytics:view` 管理员权限映射；未开放导出权限。
- ECharts 独立异步加载，运营页面自身生产包约 10.26 KB（gzip 4.09 KB）。
