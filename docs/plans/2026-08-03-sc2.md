# SC2 实施计划：身份、内容、管理员与单店模式

日期：2026-08-03

执行边界：仅 SC2；不实现 SC3 的时间锁、候补、排班算法或预约规则扩展。

## 验收目标

1. 游客无需登录即可读取默认门店、首页已发布内容、护理项目与技师公开资料。
2. 会员支持手机号 + 密码、手机号 + 短信验证码登录；注册能匹配同租户历史会员，不创建重复会员；验证码可找回密码。
3. DEMO 验证码 `888888` 只能在明确的 demo Profile 使用，非 demo 环境不得接受或返回固定验证码。
4. 运营管理平台只允许 `ADMIN`、`SUPER_ADMIN` 进入；普通管理员维护内容、项目和技师公开资料，超级管理员额外管理管理员账号。
5. `BUSINESS_MODE=SINGLE_SHOP` 时前端不写死门店编号，后端统一解析 `DEFAULT_SHOP_ID`；默认门店不存在、停用或租户不匹配时，公开目录、注册和预约均拒绝。
6. 内容状态遵循 `DRAFT → SCHEDULED → PUBLISHED → OFFLINE`，公开接口只返回到期且已发布内容。
