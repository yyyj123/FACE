# M6-07 培训与开放平台架构

## 1. 范围

M6-07 交付两个相互隔离的能力：员工培训资格闭环，以及只读服务目录开放平台。培训侧覆盖课程版本、发布、分配、员工本人开始/提交、独立账号验证、证书与有效期、不可变历史；开放平台只允许绑定门店的 `catalog:read`，不开放会员、护理、健康、支付、库存或员工联系方式。

## 2. 模块边界

- `training` 模块拥有 `training_course`、`training_record`、`training_record_history`；通过应用服务执行状态与权限校验。
- `integration` 模块拥有 `integration_client`、`integration_client_event`、`integration_request_log`；不得直接读取基础资料模块私有表。
- `masterdata.IntegrationCatalogQueryAdapter` 实现公开查询端口 `IntegrationCatalogQueryPort`，只返回服务目录白名单字段。
- 所有管理写操作复用平台幂等服务、租户/门店权限、数据库事务和审计；开放请求使用独立客户端身份，不建立员工或会员会话。

## 3. 状态与职责分离

- 课程：`DRAFT -> ACTIVE -> RETIRED`，发布后内容不可覆盖，调整必须创建新版本。
- 培训记录：`ASSIGNED -> IN_PROGRESS -> SUBMITTED -> PASSED|FAILED`；数据库兼容 `EXPIRED`、`CANCELLED` 终态。
- 员工只能开始或提交本人记录；验证账号不得验证自己的培训记录。
- 验证分数达到课程通过线时生成唯一证书号，并按上海时区计算有效期。

## 4. 开放平台安全

- 创建和轮换时仅在当前响应显示一次完整密钥；数据库只保存 SHA-256 摘要及非敏感前缀。
- 请求必须携带客户端编码、Bearer 密钥、ISO-8601 时间戳和唯一 Nonce；时间漂移最多 5 分钟。
- Nonce 按客户端唯一约束防重放；按客户端配置的每分钟限额执行数据库计数限流。
- 轮换立即使旧密钥失效；撤销后清除可用摘要并拒绝后续请求。
- 请求日志仅记录路径、方法、状态码、请求 ID、时间戳和 Nonce，不记录完整密钥或业务敏感信息。

## 5. 错误与兼容

- 400：字段、幂等键、时间戳或 Nonce 格式错误。
- 401：集成客户端、密钥或会话身份无效。
- 403：权限、门店范围、作用域或职责分离失败。
- 404：租户/门店范围内对象不存在。
- 409：状态、版本、重复 Nonce、同键异参或唯一版本冲突。
- 429：客户端分钟限流。
- 不删除或改名现有 `/api/v1`、`/api/v2`、既有 `/api/v3` 字段；迁移只新增表、索引、约束和权限。
