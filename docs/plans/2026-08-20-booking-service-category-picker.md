# 预约项目分类下拉选择计划

## 目标

- 将预约页首屏平铺的全部护理项目收进紧凑的下拉弹层。
- 按项目类别切换，只展示当前类别的项目，降低页面高度和选择负担。
- 选中项目后立即收起，并在触发器中保留项目图片、名称、时长和价格摘要。

## 交互

1. 未选择时显示“请选择护理项目”的单行入口。
2. 点击入口展开锚定式下拉弹层，不打断预约流程。
3. 弹层顶部按 `categoryName` 生成类别筛选，下面显示该类别项目。
4. 点击项目后选中并关闭弹层；再次点击入口可更换。
5. 点击外部或按 Escape 关闭，焦点返回入口。
6. 桌面项目列表双列，手机单列并限制弹层高度，内部滚动。

## 验证

## 范围

- 仅修改 `front-next` 预约项目选择交互及对应验收代码。
- 不修改项目数据、分类数据、预约规则或后端接口。
