# 商城购买方式与购物车控制增量验收记录

## 范围与现状扫描

- 商品列表、商品卡片与购物车均位于 `front-next/src/views/PointsStoreView.vue`；项目原先没有独立商品详情页。
- 本次在既有商城视图内增加响应式详情浮层，未新建第二套商城页面或路由。
- SKU 购买配置由后端字段 `cashEnabled/cashPrice`、`pointsEnabled/pointsPrice`、`comboEnabled/comboPointsPrice/comboCashPrice` 提供。
- 后端实际混合支付枚举为 `COMBINATION`；前端仅展示后端已经启用且价格有效的方式。
- 人民币格式继续复用 `front-next/src/utils/format.ts` 的 `money()`。
- PC 与移动端继续复用现有 CSS 断点与响应式体系，没有引入新 UI 库。

## 实现结果

- 商品卡片不再展示 SKU 码，也不再平铺三套价格；按现金、积分、混合支付顺序选择首个有效方式作为主价格。
- 两种及以上有效方式时动态显示 `X种购买方式`；一种时不显示数量，无有效方式时显示 `暂不可购买`。
- PC 支持悬停或点击轻量 Popover，移动端支持点击固定浮层；均可点击外部或按 Escape 关闭。
- 商品详情只展示当前 SKU 的有效方式，按钮文案随选择变为 `立即购买` 或 `立即兑换`。
- SKU 切换时保留仍有效的原选择；原方式失效时回退到新 SKU 的首个有效方式；无有效方式时清空选择。
- 购物车新增关键词搜索、增加、减少和删除；数量更新与删除均按当前购物车条目 ID 调用后端。
- 未修改下单计价、优惠、库存扣减、订单创建或支付结算规则。
