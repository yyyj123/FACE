## 响应式与交互实现

- 用户端：桌面完整 7 天表格；手机端固定技师列，日期横向滚动；点击单元格打开底部详情。
- 管理端：固定技师列和日期表头；双向滚动；点击单元格打开抽屉，展示一小时时段和最小必要预约摘要。
- 状态同时使用中文文字和颜色，不依赖颜色单独传达含义。
- 一小时格仅用于展示，后端分钟计算仍使用真实 `occupied_start_at` / `occupied_end_at`、休息、请假和有效锁定区间。

## 限制与风险

1. 当前会话没有可调用的浏览器控制绑定，因此未生成自动化桌面/手机截图；已完成 Vue 类型检查、生产构建、容器健康和真实接口验证。建议人工分别用 390px 手机宽度与桌面宽度检查一次横向滚动和抽屉手感。
2. 演示网关使用 `Secure` 访问 Cookie；命令行通过容器内网验证接口，浏览器仍按现有演示访问门禁进入。
3. 周排班聚合为固定 5 组批量查询，不按员工 × 7 天循环查库；本机演示数据性能良好，生产大门店仍应观察慢查询和响应体大小。
4. 公开技师按“门店有效任职 + 至少一个启用服务技能”筛选；无服务技能的店长不会出现在用户端技师排班中。
