# V3.0 范围与模块处置矩阵

状态：SC0 范围基线

日期：2026-08-03

适用方案：方案一——在现有系统上收缩范围并增量升级

Classification keys: `RETAIN`（保留）/ `REUSE`（复用）/ `FREEZE`（冻结）/ `ADD`（新增）。

## 判定口径

- **保留**：作为当前工程基础继续维护，不代表其全部历史功能都进入当前产品承诺。
- **复用**：两个当前产品或后续微信小程序共同调用的既有能力。
- **冻结**：代码、接口、表、迁移或容器可以保留用于兼容和追溯，但不新增、不扩展、不提供公开入口。
- **新增**：V3.0 后续阶段需要在差距分析后实现或补齐的能力；SC0 本身不实现业务功能。

## 依赖边界

当前两端和未来微信小程序只能通过统一后端共享业务规则。冻结模块不得通过新导航、新菜单、新接口消费或新数据迁移重新进入交付范围。任何“复用候选”变成正式 V3.0 能力前，必须经过 SC1 的代码、数据、接口和页面差距审计。
