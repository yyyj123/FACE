# 运营端排班恢复与技师技能增删改计划

## 范围

- 仅调整响应式运营管理平台 `admin-next` 与统一后端 `backend-next`。
- 不进入 SC3，不恢复独立技师端，不涉及微信小程序。

## 实施

1. 为周期排班规则增加显式的重新启用接口、幂等保护、版本校验、冲突校验和审计记录。
2. 在周期排班卡片中同时展示启用状态，并按状态提供“停用”或“重新启用”操作。
3. 将技师项目技能操作改为商家可理解的“新增技能、编辑技能、删除技能、恢复技能”。
4. 技能删除沿用既有版本模型：关闭当前版本并创建停用版本，保留历史预约和审计记录；恢复时创建新的启用版本。
5. 补充后端单元测试、前端构建与运行接口验证，结果记录到 `docs/verification/admin-schedule-skill-actions/`。

## 验收条件

- 已停用的周期规则仍可见，并可通过“重新启用”恢复。
- 技师技能可以新增、修改时长、删除和恢复，重复操作和并发旧版本会被安全拒绝。
- 管理端按钮具备加载/权限禁用状态，操作后自动刷新列表并显示明确结果。
- 后端测试、`admin-next` 构建和相关运行接口验证通过。
