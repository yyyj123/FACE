# M6-08 商用发布准备影响说明

## 开工检查

1. 当前阶段与任务：M6-08，总体回归、容量/安全/灾备验收、WPS 商用文档同步。
2. 输入：四份 V1.2 商用基线、M6-01 至 M6-07 代码/迁移/验收证据、现有代码规范。
3. 输出：可重复运行的发布门禁、隔离备份恢复证据、四份更新后的商用文档、恢复点与验收报告。
4. 验收：后端测试/打包、两端生产构建、全迁移/全业务链、浏览器、容量、安全、依赖审计、备份恢复、文档一致性全部通过。

## 影响模块

- 仅影响 `scripts`、`docs`、商业文档副本和备份目录。
- 不修改业务状态机、表结构、接口、权限、支付、套餐、库存或提成逻辑。
- 不连接生产数据库；容量和恢复均使用临时 MySQL 8 与虚构数据。

## 上线阈值

- 20 个并发会话、500 次混合只读请求，错误率为 0，P95 不高于 500 ms，P99 不高于 1000 ms。
- 已知跨租户/跨门店漏洞为 0；开放目录敏感字段为 0；明文集成密钥持久化为 0。
- 后端、管理端、技师/会员端高危依赖漏洞为 0；源代码和普通日志不得出现真实凭据或敏感业务数据。
- 备份 SHA-256 可核对，源库与恢复库关键汇总一致，恢复后 readiness 为 `UP`。
- 本地隔离演练 RPO=0；RTO 从开始还原到恢复库 readiness `UP` 不高于 10 分钟。

## 兼容、回滚与停机

- 本阶段没有结构回滚；任何门禁失败都停止发布，不改业务数据。
- WPS 文档先保留 V1.2 原件，再生成 M6 验收版副本；内容异常时恢复原件。
- 备份/恢复脚本只允许在 `E:\face\tmp` 和 `E:\face\backups` 下创建或清理文件。
- 全部验收完成后保存最终源码快照；关机前确认测试 MySQL、后端、Vite 和浏览器调试端口均已释放。
